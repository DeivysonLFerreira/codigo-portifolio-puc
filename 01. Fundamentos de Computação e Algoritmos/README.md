# Fundamentos de Computação e Algoritmos

*Professores: Mário Souto e Edson Ifarraguirre Moreno*

## Ementa da disciplina

- Pensamento computacional e resolução de problemas usando algoritmos.
- Análise de complexidade e desempenho de algoritmos.
- Estruturas de dados lineares e hierárquicas: listas, pilhas, filas, árvores.
- Programação em JavaScript (comandos de repetição, seleção, funções e operadores).
- Criação e manipulação de arrays, sets, maps, listas encadeadas e árvores binárias.
- Algoritmos clássicos de ordenação e busca.
- Práticas de modularização e boas práticas de programação.
- Instalação e uso do Visual Studio Code e principais extensões.
