# Programação para Web

Professores: Andrea Konzen e Luiz Fernando Planella Gonzalez

## Conteúdo da Aula

- Conceitos fundamentais e arquitetura de aplicações Web
- Diferença entre front-end e back-end, e suas principais tecnologias
- Estruturas de projeto web: modelos em camadas, MVC e arquitetura modular
- Tecnologias HTML, CSS e JavaScript: estrutura, estilo e interatividade de páginas
- Responsividade, acessibilidade e design adaptativo (mobile-first)
- Diferença entre SPA, MPA e PWA, com casos de uso práticos para cada modelo
- Manipulação do DOM, eventos e exemplos práticos de interatividade
- Introdução ao consumo e criação de APIs REST: métodos HTTP, status code, boas práticas
- Uso de SVG e media queries para layout flexível e gráfico vetorial responsivo
- Projetos práticos sugeridos: página institucional, e-commerce simples, landing page responsiva, delivery

## Dicas de Aprendizado
Comece pequeno: crie páginas estáticas, adicione estilos e evolua para inserção de lógica JavaScript.

Experimente consumir APIs públicas usando fetch, AJAX ou bibliotecas, exibindo dados dinâmicos na página.

Teste responsividade usando media queries e o modo desenvolvedor do navegador.

Organize seu código em arquivos separados para cada tecnologia.
