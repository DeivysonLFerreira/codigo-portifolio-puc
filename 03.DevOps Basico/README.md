# DevOps Básico

Professores: Fabrício Veronez e Marco Aurélio Souza Mangan

## Ementa da disciplina

- Introdução aos fundamentos de DevOps e cultura colaborativa no ciclo de desenvolvimento de software.
- Gerenciamento de configuração: automação de infraestrutura, versionamento de código, controle de dependências.
- Integração contínua (CI) e entrega/desdobramento contínuo (CD); pipelines automatizados.
- Utilização de containers e plataformas: Docker, Docker Hub, princípios do Twelve-Factor App.
- Prática com ferramentas: Git, GitHub, Maven, Gradle, npm, yarn, GitHub Actions, Jenkins, Travis.
- Observabilidade, monitoramento, logs, testes automatizados e infraestrutura como código.
- Implementação em diferentes ambientes: nuvem, local e híbrido.
- Experiências práticas: construção de pipelines, deploy automatizado, configurações de container.
- Conceitos de escalabilidade, portabilidade, automação e agilidade em equipes multidisciplinares.
