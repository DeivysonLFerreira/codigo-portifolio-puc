# Banco de Dados Relacional

Professores: Cláudio Bonel e Azriel Majdenbaum

## Ementa da disciplina

- Fundamentos de banco de dados: definição, minimundo, tipos e aplicações no cotidiano.
- Conceitos centrais: tabelas, atributos, registros, chaves primárias e estrangeiras, integridade de dados, modelo relacional.
- Engenharia de requisitos para modelagem de dados: levantamento, análise e validação junto aos usuários.
- Diagrama Entidade-Relacionamento (DER), entidades, relacionamentos, cardinalidade, restrições (constraints).
- Práticas com SQL: comandos essenciais (DDL, DML), tipos de dados, criação e manipulação de tabelas e registros.
- Consultas básicas, filtros, agrupamentos, ordenação, junções (joins).
- Introdução ao ORM (Object Relational Mapping), exemplos em Python com SQLAlchemy.
- Ferramentas práticas: SQLite, SQLite Studio, ambientes gráficos e boas práticas de documentação.
- Exercícios práticos: modelagem de um sistema real de cadastro e vendas.
- Técnicas de diagramação: draw.io, desenvolvimento colaborativo e documentação clara.
- Boas práticas, cuidados profissionais, integridade, segurança e validação dos modelos.
