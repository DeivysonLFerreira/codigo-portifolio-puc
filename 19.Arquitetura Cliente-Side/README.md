# Arquitetura Cliente-Side

Professores: Andre Luiz Mendes Pereira, Julio Henrique Araujo Pereira Machado

---

## Ementa e Temas Centrais

- Fundamentos de arquitetura client-side: da arquitetura cliente-servidor à moderna web SPA.
- Estudo do contexto, sistemas, componentes e stakeholders envolvidos.
- Ambientes multiplataforma: navegadores, mobiles, dispositivos IoT, assistentes virtuais, TVs, consoles e integração de APIs externas.
- Principais tecnologias: HTML semântico, CSS modular (BEM, Styled Components), frameworks JavaScript (React, Angular, Vue), TypeScript.
- Estruturas arquiteturais: camadas, Onion Architecture, Arquitetura Hexagonal (Ports & Adapters), padrões para front-end.
- Comunicação com back-end: APIs RESTful, GraphQL, mensageria e estratégias BFF (Back-end for Front-end).
- Estratégias de renderização: Client-side rendering, Server-side rendering, Universal/Hybrid rendering e implicações em SEO e experiência do usuário.
- Práticas de acessibilidade e uso de Design Systems (ex: Material Design, Datalation).
- Performance, CDN, gerenciamento de dependências, segurança (XSS, HTTPS) e boas práticas de manutenção.
