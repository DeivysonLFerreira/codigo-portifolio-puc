# Bancos de Dados NoSQL

Professores: Eduardo Henrique Pereira de Arruda e Vinícius Kroth

## Ementa da disciplina

- Revisão do conceito de banco de dados e dos motivos históricos/tecnológicos que levaram ao surgimento de bancos NoSQL.
- Diferenças fundamentais entre bancos relacionais e NoSQL; comparação de paradigmas e aplicações.
- Tipos e famílias de bancos NoSQL: chave-valor (ex: Redis), documento (ex: MongoDB), colunar (ex: Cassandra), grafo (ex: Neo4j).
- Conceitos de escalabilidade, distribuição, replicação, consistência, partição (sharding) e alta disponibilidade.
- Modelagem NoSQL: como projetar documentos, coleções, famílias de colunas e grafos de acordo com o uso.
- Vantagens, desvantagens e dilemas (ex: trade-offs CAP, ACID vs BASE).
- Exemplos práticos de comandos MongoDB, queries em grafos (Cypher), consultas eficientes em Redis e Cassandra.
- Critérios para a escolha de banco de dados em diferentes cenários: arquiteturas modernas, big data, aplicações web escaláveis.
- Estratégias de integração entre bancos NoSQL e relacionais ("polyglot persistence").
- Experiências reais de projetos, boas práticas, erros frequentes e dicas de arquitetura.
